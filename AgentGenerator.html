Quick Start

Export the generated Python agent and install the dependencies required for working with structured datasets and machine learning models. 

pip install pandas numpy scikit-learn openpyxl joblib

from openmind_agent import OpenMindAgent
import pandas as pd

data = pd.read_csv("your_data.csv")

agent = OpenMindAgent(
    model_type="classification",
    algorithm="random_forest"
)

agent.train(
    data,
    target_col="target_column"
)

prediction = agent.predict({
    "feature1": 10
})
